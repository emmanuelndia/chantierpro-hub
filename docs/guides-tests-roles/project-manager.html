Guide role

PROJECT_MANAGER
tests a mener

Retour au kit

Objectif du role

  • Piloter ses projets et chantiers.
  • Confier des sites aux superviseurs generaux.
  • Planifier les ressources sur ses propres sites.
  • Consulter les rapports de ses projets.

Prerequis

  • Compte PROJECT_MANAGER actif.
  • Au moins deux ressources terrain actives.
  • Au moins un GENERAL_SUPERVISOR disponible.
  • Acces web et mobile si prevu.

Parcours principal

  1. Verifier que seuls vos projets sont visibles.
  2. Creer un projet puis modifier seulement un champ.
  3. Creer plusieurs chantiers dans le projet.
  4. Modifier seulement les coordonnees GPS d'un chantier.
  5. Confier un site A puis un site B a un GENERAL_SUPERVISOR.
  6. Confier le site A a un second GENERAL_SUPERVISOR.
  7. Ouvrir le planning et verifier que seuls vos chantiers apparaissent.
  8. Affecter une ressource active a un chantier.
  9. Affecter la meme ressource a deux chantiers le meme jour.
  10. Ajouter plusieurs taches a la meme ressource.
  11. Ouvrir la vue semaine puis cliquer sur un jour pour voir le detail.
  12. Consulter et telecharger un rapport autorise.

Resultats attendus

  • Le perimetre projet est respecte.
  • Les modifications partielles ne cassent pas les autres champs.
  • Les ressources restent tournantes entre projets.
  • Les taches sont regroupees par ressource dans le planning.

Anomalies a noter

  • Projet d'un autre chef visible.
  • Ressource active absente.
  • Affectation refusee alors qu'elle devrait passer.
  • Vue semaine non cliquable ou mauvais jour ouvert.
  • Rapport attendu introuvable.
