Guide role

COORDINATOR
tests a mener

Retour au kit

Objectif du role

  • Suivre les rapports terrain autorises.
  • Verifier les filtres et details.
  • Telecharger les rapports accessibles.
  • Controler la lisibilite des informations.

Prerequis

  • Compte COORDINATOR actif.
  • Plusieurs rapports existants.
  • Plusieurs projets ou chantiers dans le perimetre.
  • Acces web et mobile si prevu.

Parcours principal

  1. Se connecter et verifier les menus visibles.
  2. Ouvrir la liste des rapports.
  3. Filtrer par date, chantier, ressource et statut.
  4. Ouvrir plusieurs details de rapports.
  5. Verifier les informations principales.
  6. Telecharger un rapport autorise.
  7. Tester un filtre sans resultat pour verifier le message vide.

Resultats attendus

  • Les rapports du perimetre sont visibles.
  • Les filtres fonctionnent.
  • Les details sont lisibles.
  • Les telechargements autorises fonctionnent.

Anomalies a noter

  • Erreur 401 ou 403 injustifiee.
  • Rapport attendu absent.
  • Filtre sans effet.
  • Telechargement refuse a tort.
  • Informations difficiles a lire.
