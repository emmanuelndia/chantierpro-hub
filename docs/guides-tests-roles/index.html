ChantierPro

Application web + mobile

Semaine de recette

Objectif

Chaque testeur suit le guide de son role pour verifier les actions qu'il peut reellement faire dans ChantierPro. Le but est de trouver les bugs, les blocages, les lenteurs et les ecrans difficiles a comprendre.

Regles communes

  • Utiliser le compte attribue.
  • Aller jusqu'au bout des actions.
  • Noter role, ecran, action, attendu, obtenu et gravite.
  • Ajouter une capture ou video si possible.
