Guide role

ADMIN
tests a mener

Retour au kit

Objectif du role

  • Gerer les utilisateurs.
  • Verifier les droits principaux.
  • Controler galerie et logs.
  • S'assurer que les nouveaux profils apparaissent dans les bons selecteurs.

Prerequis

  • Compte ADMIN actif.
  • Acces web et mobile.
  • Au moins un projet et un chantier existants.
  • Un fichier de suivi des bugs ouvert.

Parcours principal

  1. Se connecter en ADMIN et verifier le tableau de bord.
  2. Creer un SUPERVISOR, un GENERAL_SUPERVISOR et un PROJECT_MANAGER.
  3. Modifier un utilisateur existant.
  4. Desactiver puis reactiver un utilisateur.
  5. Reinitialiser un mot de passe.
  6. Rechercher et filtrer les utilisateurs.
  7. Ouvrir la galerie et changer de chantier.
  8. Ouvrir les logs de suppression.

Resultats attendus

  • Les creations et modifications fonctionnent.
  • Les nouveaux utilisateurs actifs apparaissent dans les selecteurs terrain.
  • Les profils inactifs n'apparaissent plus dans les choix operationnels.
  • La galerie et les logs se chargent correctement.

Anomalies a noter

  • Utilisateur absent apres creation.
  • Role incorrect dans un selecteur.
  • Galerie vide ou photo impossible a ouvrir.
  • Menu interdit visible.
  • Message d'erreur incomprehensible.
