# 1-a) Problèmes / Objectifs de Chantier Pro

## Module 1 — Référentiel Utilisateurs & Authentification
1. Centraliser la gestion des utilisateurs et de leurs rôles (Technicien, Chef de Projet, RH, Direction, Admin).
2. Sécuriser l'accès à l'application via une authentification robuste (JWT).
3. Garantir l'intégrité des sessions sur mobile pour les travailleurs de terrain.

## Module 2 — Projets & Chantiers
1. Structurer le découpage opérationnel entre Projets (entité contractuelle/globale) et Chantiers (entité géographique/exécution).
2. Définir précisément les zones de travail (coordonnées GPS et rayon de géofencing).
3. Assigner les ressources (techniciens) aux projets pour limiter le bruit informationnel sur le terrain.

## Module 3 — Pointage Géolocalisé
1. Éliminer la fraude et les erreurs de saisie manuelle des heures de présence.
2. Garantir que le pointage n'est possible que si le technicien est physiquement sur site (rayon de 2km).
3. Automatiser le calcul de la durée de présence par session de travail.

## Module 4 — Documentation Photographique
1. Centraliser la documentation visuelle des chantiers pour éviter l'usage de canaux non sécurisés (WhatsApp, galeries personnelles).
2. Conférer une valeur probatoire aux photos via l'horodatage et la géolocalisation immuables.
3. Assurer la pérennité des données en empêchant la suppression par le personnel de terrain.
4. Maintenir une piste d'audit complète pour toute suppression effectuée par l'encadrement.

## Module 5 — RH & Suivi des Heures
1. Automatiser la consolidation mensuelle des heures pour la paie.
2. Offrir une visibilité granulaire sur les sessions de pointage et les sites visités.
3. Faciliter l'export des données vers des outils tiers (Excel, logiciels de paie).

## Module 6 — Pilotage Direction & Admin
1. Fournir une vision consolidée multi-projets en temps réel pour la prise de décision.
2. Assurer la gouvernance du système (gestion des comptes, logs de suppression).
3. Mesurer la performance opérationnelle globale de l'entreprise.
