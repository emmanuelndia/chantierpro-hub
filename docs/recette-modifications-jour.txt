1. Import Excel / CSV des chantiers
-----------------------------------

Ce qui a ete fait :
- Ajout d'un import de chantiers depuis le detail web d'un projet.
- Ajout d'un modele Excel telechargeable.
- Ajout d'une previsualisation avec lignes valides, erreurs et warnings.
- Ajout d'un commit qui cree uniquement les lignes valides.
- Validation ligne par ligne :
  - nom obligatoire ;
  - latitude / longitude valides ;
  - surface obligatoire ;
  - date debut obligatoire ;
  - responsable_gs_email obligatoire et doit etre un GS actif ;
  - adresse facultative ;
  - description facultative ;
  - rayon par defaut si vide ;
  - doublons de nom bloques.

Ou regarder :
- components/project-detail-page.tsx
- lib/site-import.ts
- app/api/projects/[id]/sites/import/template/route.ts
- app/api/projects/[id]/sites/import/preview/route.ts
- app/api/projects/[id]/sites/import/commit/route.ts
- types/projects.ts

Comment tester :
1. Se connecter en PROJECT_MANAGER, DIRECTION ou ADMIN.
2. Ouvrir un projet web.
3. Cliquer sur Importer des chantiers.
4. Telecharger le modele.
5. Remplir 2 ou 3 lignes valides.
6. Uploader le fichier.
7. Verifier la previsualisation.
8. Cliquer sur Importer les lignes valides.

Resultat attendu :
- Les chantiers valides sont crees.
- Les lignes invalides restent bloquees avec un message clair.
- Un PM ne peut importer que dans ses propres projets.

Tests d'erreurs a faire :
- latitude invalide ;
- responsable_gs_email inexistant ;
- responsable qui n'est pas GENERAL_SUPERVISOR ;
- deux lignes avec le meme nom ;
- nom deja existant dans le projet.


2. Limites avancees de chantier par polygone
--------------------------------------------

Ce qui a ete fait :
- Ajout du geofencing avance :
  - RADIUS par defaut ;
  - POLYGON optionnel.
- Ajout de geofenceType et geofencePolygon sur Site.
- Extension du SiteLocationPicker pour dessiner une limite precise.
- Le pointage utilise le polygone si le chantier en a un.
- Sinon, le rayon existant continue de fonctionner.
- Compatibilite gardee avec les anciens chantiers.

Ou regarder :
- prisma/schema.prisma
- components/site-location-picker.tsx
- components/project-detail-page.tsx
- components/mobile-site-form-page.tsx
- lib/projects.ts
- lib/clock-in.ts
- app/api/sites/[id]/clock-in/route.ts
- app/api/sync/batch/route.ts
- types/projects.ts

Comment tester :
1. Creer un chantier normalement sans dessiner de limite.
2. Verifier qu'il reste en mode rayon.
3. Creer ou modifier un autre chantier.
4. Activer Dessiner la limite.
5. Placer au moins 3 points.
6. Fermer la limite.
7. Enregistrer.
8. Tester le pointage :
   - dans le polygone : autorise ;
   - hors du polygone : refuse.

Resultat attendu :
- Les anciens chantiers continuent avec le rayon.
- Les nouveaux chantiers polygonaux utilisent la limite precise.
- Le message hors zone indique que l'utilisateur est hors de la limite precise.

Ce qui a ete fait :

  - NEGOTIATION_RESOURCE ;
  - FLEET_MANAGER ;

  - les taches ON_SITE declenchent le flux terrain ;

- Mise a jour des libelles UI :

Comment tester :
1. En ADMIN, creer :
   - un Responsable Negociation ;
   - une Ressource Negociation ;
   - un Responsable Parc Auto ;
   - un Chauffeur.
2. Se connecter comme Responsable Negociation.
3. Ouvrir Planning.
4. Verifier qu'il voit tous les projets/sites actifs.
5. Verifier que le select ressource ne propose que les Ressources Negociation.
6. Creer une tache ON_SITE.
7. Se connecter comme Ressource Negociation.
8. Verifier que la tache apparait dans les taches/chantiers du jour.

Meme test pour Parc Auto :
- Responsable Parc Auto assigne un Chauffeur.

Resultat attendu :
- Les managers metier ne voient pas Perimetres GS.
- Ils ne peuvent pas assigner les ressources des autres cellules metier.
- Les ressources terrain peuvent pointer/photo/rapport si tache ON_SITE.

Comment tester :
1. En PM/GS/manager metier, creer une tache avec cible 80%.
2. Ajouter un objectif texte.
3. Se connecter avec la ressource.
4. Ouvrir Planning mobile.
5. Cliquer sur Mettre a jour l'avancement.
6. Declarer 50%.

Resultat attendu :
- Statut Partiel.
- Ecart -30%.

Suite :
1. Declarer 80% ou plus.
2. Verifier statut Atteint.
3. Cocher Blocage avec commentaire.
4. Verifier statut Bloque.
5. Soumettre le rapport de session.

Resultat attendu :
- Le rapport reprend la progression et le blocage.
- Les dashboards indiquent les objectifs atteints/partiels/bloques.

Test offline :
1. Couper internet.
2. Declarer une progression mobile.
3. Reconnecter.
4. Synchroniser.

Resultat attendu :
- L'update remonte au serveur.
