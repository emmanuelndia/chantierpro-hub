Rappels testeurs

  • Utilisez uniquement le compte attribué
  • Allez jusqu'au bout des actions
  • Faites une capture si un bug apparaît
  • Notez rôle, écran, action, résultat et gravité
  • Participez au point quotidien de 15 minutes

Niveaux de gravité

  • Bloquant — impossible de continuer
  • Majeur — fonctionne mais incorrectement
  • Mineur — gêne légère, contournement possible
  • Ergonomie — pas un bug, mais à améliorer

Suivi quotidien

  • Un responsable collecte les bugs chaque jour
  • Les bloquants sont retestés avant vendredi
  • Les corrections critiques peuvent déclencher un redéploiement
  • Les retours ergonomie sont conservés pour la suite

Décision finale

  • GO — ouverture possible
  • GO avec réserves — ouverture limitée et suivie
  • NO-GO — correction obligatoire avant ouverture
  • La décision se prend vendredi après les retests
