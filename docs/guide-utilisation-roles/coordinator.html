Guide Coordinateur

Role : COORDINATOR

Version web + version mobile terrain

Objectif du role

Le coordinateur suit les rapports terrain, verifie les informations, telecharge les documents autorises et peut aussi etre assigne comme ressource terrain sur un chantier.

Ecrans accessibles

Web : Tableau de bord, Rapports terrain, Presences equipe et Profil.

Mobile : Accueil, chantiers du jour, Pointer, Photo, Historique, Rapports, Sync/offline et Profil si le coordinateur est utilise sur le terrain.

Version webVersion mobileReglesProblemes frequents

Version web

Bureau

Ouvrir le tableau de bord

Chemin : Menu lateral > Tableau de bord.

Ou appuyer : entree Tableau de bord.

Resultat attendu : les rapports recents et indicateurs utiles s'affichent.

Consulter la liste des rapports

Chemin : Menu lateral > Rapports terrain.

Ou appuyer : ouvrir la page Rapports terrain.

Resultat attendu : les rapports accessibles s'affichent avec leurs informations principales.

Telecharger un rapport

Chemin : Liste ou detail rapport.

Ou appuyer : Telecharger PDF, XLSX, CSV ou TXT selon ce qui est propose.

Resultat attendu : le fichier se telecharge sans afficher de statut inutile dans le document final.

Consulter les presences equipe

Chemin : Presences equipe.

Ou appuyer : filtres periode, ressource ou type de pointage.

Resultat attendu : les presences affichees viennent des pointages reels.

Version mobile

Terrain

Ouvrir l'accueil mobile

Chemin : Onglet Accueil.

Ou appuyer : cartes du jour et raccourcis.

Resultat attendu : les informations utiles de la journee s'affichent si le coordinateur est assigne.

Pointer sur un chantier

Chemin : Onglet Pointer.

Ou appuyer : Pointer entree, Pause, Reprendre ou Pointer sortie selon l'etat.

Resultat attendu : le pointage utilise la position GPS et respecte les chantiers assignes.

Prendre une photo

Chemin : Onglet Photo.

Ou appuyer : choisir chantier, choisir tache si besoin, puis prendre photo.

Resultat attendu : la photo est envoyee ou placee en attente si le reseau est coupe.

Consulter les rapports mobile

Chemin : Onglet Rapports.

Ou appuyer : ouvrir ou filtrer un rapport.

Resultat attendu : les rapports accessibles restent lisibles sur telephone.

Regles importantes

  • Le coordinateur consulte surtout les rapports et les presences.
  • S'il est assigne comme ressource, il utilise les memes ecrans terrain qu'un superviseur.
  • Les telechargements dependent des droits du role et du perimetre.

Si une action manque

  • Retirer les filtres trop restrictifs.
  • Verifier que le rapport est bien soumis.
  • Verifier que le coordinateur est assigne aujourd'hui s'il doit pointer ou prendre une photo.
