Comment utiliser ce guide

Chaque utilisateur doit ouvrir le guide de son role. Ce document sert a utiliser l'application au quotidien, pas a suivre une procedure de verification.

Chaque guide separe la version web et la version mobile. Pour chaque action, l'utilisateur voit le chemin a suivre, le bouton a utiliser, le resultat attendu et la capture de l'ecran juste a cote.

Le guide ne remplace pas les droits de l'application : si un bouton n'apparait pas, verifier d'abord le role du compte connecte et le perimetre attribue.

Regles communes

  • Se connecter avec le compte donne par l'administrateur.
  • Utiliser le menu lateral sur web et les onglets du bas sur mobile.
  • Les actions secondaires sont souvent dans le bouton a trois points.
  • Les filtres servent a reduire une liste par date, projet, chantier, ressource ou statut.
  • Le menu Profil permet de consulter le compte et de se deconnecter.

Web ou mobile ?

  • Le web sert surtout a l'administration, au pilotage, aux rapports et aux vues larges.
  • Le mobile sert au terrain, au suivi rapide, au pointage, aux photos et aux actions urgentes.
  • Certains roles ont les deux versions, mais pas les memes actions partout.

Si une action manque

  • Verifier que vous etes connecte avec le bon role.
  • Verifier le perimetre : projet, chantier confie ou site assigne.
  • Rafraichir la page si une modification vient d'etre faite par un autre utilisateur.
  • Signaler le probleme avec le role, l'ecran et l'action attendue.
