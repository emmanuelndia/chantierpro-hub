Guide Chef de projet

Role : PROJECT_MANAGER

Version web + version mobile

Objectif du role

Le chef de projet pilote ses propres projets et chantiers. Il cree les chantiers, confie des sites aux superviseurs generaux, planifie les ressources terrain et consulte les rapports de son perimetre.

Les ressources terrain ne lui appartiennent pas : il peut assigner une ressource active, meme si elle travaille aussi sur un autre projet.

Ecrans accessibles

Web : Tableau de bord, Mes projets, detail projet, chantiers, planning, perimetres GS, galerie photos, rapports terrain, presences equipe et profil.

Mobile : Accueil, projets, detail chantier, planning, galerie, perimetres GS et profil.

Version web

Bureau

Ouvrir le tableau de bord

Chemin : Menu lateral > Tableau de bord.

Ou appuyer : cliquer sur l'entree Tableau de bord.

Resultat attendu : les indicateurs de vos projets, chantiers et activites recentes s'affichent.

Consulter mes projets

Chemin : Menu lateral > Mes projets.

Ou appuyer : utiliser la recherche, les filtres ou cliquer sur une carte projet.

Resultat attendu : seuls les projets dont vous etes responsable apparaissent.

Creer un projet

Chemin : Menu lateral > Mes projets.

Ou appuyer : bouton Nouveau projet.

Resultat attendu : le projet est cree et rattache a votre compte de chef de projet.

Ouvrir le detail d'un projet

Chemin : Mes projets > cliquer sur le projet.

Ou appuyer : carte projet ou bouton Ouvrir le detail.

Resultat attendu : vous voyez les chantiers, les equipes, les photos et les actions liees au projet.

Creer ou modifier un chantier

Chemin : Detail projet > Nouveau chantier, ou menu du chantier > Modifier.

Ou appuyer : remplir le formulaire puis Enregistrer.

Resultat attendu : le chantier est ajoute ou corrige. Une modification partielle, comme les coordonnees GPS seulement, doit etre acceptee.

Confier un chantier a un superviseur general

Chemin : Menu lateral > Perimetres GS.

Ou appuyer : Nouveau perimetre, choisir le GS, le chantier et les dates.

Resultat attendu : le superviseur general peut faire le planning uniquement sur ce chantier confie.

Planifier une ressource terrain

Chemin : Menu lateral > Planning.

Ou appuyer : Ajouter une tache, choisir le chantier, la ressource, la tache et la progression cible.

Resultat attendu : la ressource recoit une tache sur un chantier de vos projets. Elle peut aussi avoir d'autres taches ailleurs.

Consulter les presences chantier

Chemin : Detail chantier ou Presences equipe.

Ou appuyer : ouvrir l'onglet Presences ou utiliser les filtres.

Resultat attendu : les ressources presentes viennent des pointages reels du jour, pas seulement des equipes.

Consulter les rapports terrain

Chemin : Menu lateral > Rapports terrain.

Ou appuyer : filtrer par periode, projet, chantier ou ressource, puis ouvrir le rapport.

Resultat attendu : les rapports de vos projets sont lisibles et telechargeables selon les droits.

Consulter la galerie photos

Chemin : Menu lateral > Galerie photos.

Ou appuyer : choisir un projet, un chantier, puis ouvrir une photo.

Resultat attendu : les photos des chantiers de vos projets s'affichent.

Version mobile

Telephone

Ouvrir l'accueil chef de projet

Chemin : Onglet Accueil.

Ou appuyer : cartes de resume ou raccourcis visibles.

Resultat attendu : vous voyez rapidement vos projets, chantiers et activites utiles sur telephone.

Gerer les projets sur mobile

Chemin : Onglet Projets.

Ou appuyer : + Nouveau projet, recherche, carte projet.

Resultat attendu : vous pouvez creer un projet ou ouvrir un projet existant depuis le telephone.

Ouvrir un chantier sur mobile

Chemin : Projets > projet > chantier.

Ou appuyer : carte chantier puis onglets Presences, Photos ou Rapports.

Resultat attendu : vous consultez le detail operationnel d'un chantier depuis le telephone.

Planifier depuis mobile

Chemin : Onglet Planning.

Ou appuyer : Ajouter une tache, choisir le chantier et la ressource.

Resultat attendu : le chef de projet assigne une ressource terrain sur un de ses chantiers.

Consulter la galerie mobile

Chemin : Onglet Galerie.

Ou appuyer : choisir un chantier puis ouvrir une photo.

Resultat attendu : les photos des chantiers de vos projets sont visibles sur telephone.

Gerer les perimetres GS sur mobile

Chemin : Onglet Perimetres.

Ou appuyer : Nouveau perimetre ou ouvrir une carte existante.

Resultat attendu : un site de vos projets peut etre confie a un superviseur general.

Ouvrir le profil et se deconnecter

Chemin : Onglet Profil.

Ou appuyer : Profil, changer mot de passe si besoin, puis Deconnexion.

Resultat attendu : le compte est consulte ou la session est fermee proprement.

Regles importantes

  • Le chef de projet voit ses propres projets et les chantiers de ces projets.
  • Il peut affecter toute ressource terrain active sur ses chantiers, meme si cette ressource vient d'un autre projet.
  • Un superviseur general ne planifie pas automatiquement tous vos chantiers : il faut lui confier les sites concernes.
  • Le planning gere des taches. Une meme ressource peut avoir plusieurs taches le meme jour.
  • Les presences viennent des pointages reels, pas seulement des membres d'equipe.

Si une action manque

  • Verifier que le projet ou le chantier est actif.
  • Verifier que le chantier appartient bien a l'un de vos projets.
  • Verifier que la ressource est active et a un role terrain.
  • Si un site n'apparait pas dans le planning d'un GS, verifier qu'il lui a ete confie dans Perimetres GS.
  • Si une photo ou un rapport ne s'affiche pas, verifier les filtres projet, chantier et periode.
