Guide Superviseur terrain

Role : SUPERVISOR

Version mobile principalement

Objectif du role

Le superviseur terrain execute sa journee dans l'application mobile : voir ses chantiers assignes, pointer, prendre des photos, suivre ses taches, rediger les rapports et synchroniser les actions si le reseau revient.

Ecrans accessibles

Mobile : Accueil, Chantiers du jour, Pointer, Photo, Historique, Rapport session, Sync/offline et Profil.

Web : pas d'espace de pilotage principal. L'usage normal du superviseur est mobile.

Version mobile

Terrain

Ouvrir l'accueil terrain

Chemin : Onglet Accueil.

Ou appuyer : cartes et raccourcis du jour.

Resultat attendu : les chantiers, alertes et actions utiles de la journee sont visibles.

Voir les chantiers du jour

Chemin : Accueil ou Pointer.

Ou appuyer : choisir un chantier assigne aujourd'hui.

Resultat attendu : les chantiers viennent du planning du jour. Un site proche non assigne ne doit pas masquer un site assigne.

Pointer entree, pause, reprise ou sortie

Chemin : Onglet Pointer.

Ou appuyer : Pointer entree, Pause, Reprendre ou Pointer sortie selon l'etat affiche.

Resultat attendu : la session de pointage suit la bonne sequence sur le chantier selectionne.

Verifier la distance GPS

Chemin : Pointer > chantier selectionne.

Ou appuyer : lire la distance, la precision et la source de position.

Resultat attendu : l'utilisateur sait si la position est live ou cachee. La selection du site ne remplace jamais la localisation.

Fermer une session a distance

Chemin : Pointer > chantier avec session ouverte.

Ou appuyer : Fermer session a distance si l'application le propose.

Resultat attendu : la sortie est enregistree avec la position reelle, la distance et un commentaire de tracabilite.

Prendre une photo chantier

Chemin : Onglet Photo.

Ou appuyer : choisir le chantier, puis prendre photo.

Resultat attendu : la photo est envoyee en ligne ou mise en attente hors ligne.

Lier une photo a une tache

Chemin : Photo > chantier > tache.

Ou appuyer : choisir la tache avant de capturer.

Resultat attendu : la photo est rattachee a la bonne tache de planning.

Rediger le rapport apres sortie

Chemin : apres Pointer sortie.

Ou appuyer : remplir le volet rapport puis Envoyer.

Resultat attendu : le rapport est lie a la session terminee. Aucune photo n'est a attacher au rapport.

Rattraper un rapport manquant

Chemin : Historique > session avec Rapport manquant.

Ou appuyer : Rediger le rapport.

Resultat attendu : un rapport saute peut etre envoye plus tard, tant qu'il n'existe pas deja.

Consulter l'historique

Chemin : Onglet Historique.

Ou appuyer : ouvrir une session, un rapport ou une photo.

Resultat attendu : les actions personnelles restent consultables.

Mode offline

Sans reseau

Utiliser l'application sans reseau

Chemin : application mobile deja ouverte ou PWA installee.

Ou appuyer : Accueil, Pointer, Photo, Historique ou Sync.

Resultat attendu : les ecrans terrain prepares restent accessibles et les actions se mettent en attente.

Synchroniser les actions en attente

Chemin : Onglet Sync ou retour reseau.

Ou appuyer : Synchroniser maintenant si la synchronisation automatique ne suffit pas.

Resultat attendu : pointages, photos, rapports et actions en attente sont envoyes au serveur.

Regles importantes

  • Les chantiers du jour viennent du planning, pas de l'equipe uniquement.
  • La selection manuelle du chantier ne remplace pas le controle GPS.
  • L'entree reste liee a la presence physique sur le chantier.
  • La sortie distante est autorisee uniquement avec tracabilite quand la ressource est deplacee.
  • Les rapports ne demandent pas d'attacher des photos.

Si une action manque

  • Verifier que le chantier est assigne aujourd'hui.
  • Verifier que le GPS est disponible ou qu'une position recente existe.
  • Verifier l'onglet Sync si une action reste en attente.
  • Si un rapport manque, passer par Historique > Rapport manquant.
