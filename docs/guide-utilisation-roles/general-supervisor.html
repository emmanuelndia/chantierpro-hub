Guide Superviseur general

Role : GENERAL_SUPERVISOR

Version web + version mobile

Objectif du role

Le superviseur general organise le travail sur les sites qui lui sont confies. Il planifie les ressources terrain, suit les rapports, gere les equipes et peut aussi etre assigne comme ressource sur un chantier.

Ecrans accessibles

Web : Tableau de bord, Planning, Rapports terrain, Presences equipe, Profil.

Mobile : Accueil, Planning, Equipes, Rapports, Pointer, Photo, Historique, Sync/offline et Profil selon les affectations.

Version web

Bureau

Consulter le tableau de bord

Chemin : Menu lateral > Tableau de bord.

Ou appuyer : entree Tableau de bord.

Resultat attendu : les sites confies et les indicateurs utiles au pilotage s'affichent.

Ouvrir le planning des sites confies

Chemin : Menu lateral > Planning.

Ou appuyer : choisir une date ou la vue semaine.

Resultat attendu : seuls les sites explicitement confies au GS sont planifiables.

Ajouter une tache

Chemin : Planning > Ajouter une tache.

Ou appuyer : choisir site, ressource, action et progression cible.

Resultat attendu : une ressource terrain active est assignee sur le site confie.

Consulter les rapports terrain

Chemin : Menu lateral > Rapports terrain.

Ou appuyer : filtres periode, chantier ou ressource, puis ouvrir un rapport.

Resultat attendu : les rapports des sites confies sont consultables.

Suivre les presences

Chemin : Presences equipe ou detail chantier.

Ou appuyer : filtres periode, ressource, chantier.

Resultat attendu : les presences affichent les pointages reels des ressources.

Version mobile

Telephone

Ouvrir l'accueil mobile

Chemin : Onglet Accueil.

Ou appuyer : raccourcis Planning, Equipes ou Rapports.

Resultat attendu : le GS accede vite a ses operations du jour.

Planifier depuis mobile

Chemin : Onglet Planning.

Ou appuyer : Ajouter une tache.

Resultat attendu : creation rapide d'une tache sur un site confie.

Gerer les equipes

Chemin : Onglet Equipes.

Ou appuyer : + Nouvelle equipe, ouvrir une equipe ou Ajouter membre.

Resultat attendu : l'equipe est geree comme structure d'organisation et d'historique.

Consulter les rapports mobile

Chemin : Onglet Rapports.

Ou appuyer : filtres puis ouvrir un rapport.

Resultat attendu : les rapports accessibles restent lisibles sur telephone.

Si le GS est assigne comme ressource terrain

Terrain

Pointer et prendre des photos

Chemin : Onglets Pointer ou Photo.

Ou appuyer : choisir le chantier assigne, puis Pointer entree/sortie ou prendre photo.

Resultat attendu : le GS agit comme ressource terrain sur le chantier assigne, sans obtenir automatiquement le droit de le planifier.

Regles importantes

  • Un GS planifie uniquement les sites qui lui sont confies explicitement.
  • Etre assigne comme ressource sur un autre site ne donne pas le droit de planifier ce site.
  • Plusieurs GS peuvent etre confies au meme site.
  • Les ressources terrain restent globales et peuvent etre assignees par plusieurs responsables.

Si une action manque

  • Verifier que le site est actif.
  • Verifier que le site est bien confie au GS pour la periode.
  • Verifier que la ressource a un role terrain actif.
  • Si un chantier apparait pour pointer mais pas pour planifier, c'est normal s'il est seulement assigne comme ressource.
