Guide Admin

Role : ADMIN

Version web + version mobile

Objectif du role

L'administrateur gere les comptes, verifie les acces, consulte la galerie, suit les logs de suppression et intervient rapidement quand un utilisateur est bloque.

Ecrans accessibles

Web : Tableau de bord, Utilisateurs, Galerie photos, Logs de suppression, projets en consultation, rapports selon droits et profil.

Mobile : Accueil admin, Utilisateurs, Galerie, Logs et Profil. L'admin mobile est volontairement online-only.

Version web Version mobile Regles importantes Problemes frequents

Version web

Bureau

Ouvrir le tableau de bord admin

Chemin : Menu lateral > Tableau de bord.

Ou appuyer : entree Tableau de bord.

Resultat attendu : les compteurs et indicateurs principaux de l'application s'affichent.

Creer un utilisateur

Chemin : Menu lateral > Utilisateurs.

Ou appuyer : Nouveau utilisateur, remplir les informations et enregistrer.

Resultat attendu : le compte est cree avec le bon role et le bon statut.

Modifier, desactiver ou reactiver un compte

Chemin : Utilisateurs > ligne ou carte utilisateur.

Ou appuyer : menu a trois points puis Modifier, Desactiver ou Reactiver.

Resultat attendu : l'action cible le bon utilisateur et la liste se met a jour.

Reinitialiser un mot de passe

Chemin : Utilisateurs > menu a trois points.

Ou appuyer : Reset MDP, puis confirmer.

Resultat attendu : un nouveau mot de passe est genere ou applique selon le parcours de l'application.

Consulter la galerie photos

Chemin : Menu lateral > Galerie photos.

Ou appuyer : choisir un chantier, ouvrir une photo.

Resultat attendu : les photos stockees sur R2 s'affichent correctement.

Auditer les logs de suppression

Chemin : Menu lateral > Logs de suppression.

Ou appuyer : utiliser les filtres date, auteur ou export.

Resultat attendu : les suppressions restent tracables avec auteur, date, chantier et motif.

Version mobile

Telephone

Ouvrir l'accueil admin mobile

Chemin : Onglet Accueil.

Ou appuyer : raccourcis Utilisateurs, Galerie ou Logs.

Resultat attendu : l'admin accede vite aux interventions utiles sur telephone.

Gerer les utilisateurs sur mobile

Chemin : Onglet Utilisateurs.

Ou appuyer : recherche, filtres, Nouveau utilisateur ou menu a trois points.

Resultat attendu : creation, modification, activation et reset MDP restent possibles sur telephone.

Consulter la galerie mobile

Chemin : Onglet Galerie.

Ou appuyer : choisir un chantier puis ouvrir une photo.

Resultat attendu : la galerie s'ouvre en ligne pour l'admin.

Consulter les logs sur mobile

Chemin : Onglet Logs.

Ou appuyer : filtres date ou auteur, puis ouvrir une carte log.

Resultat attendu : les suppressions sont lisibles sur telephone.

Ouvrir le profil

Chemin : Onglet Profil.

Ou appuyer : Profil, changer mot de passe si besoin, Deconnexion.

Resultat attendu : la session admin est fermee proprement si l'utilisateur se deconnecte.

Regles importantes

  • L'admin peut gerer les utilisateurs, mais il doit toujours verifier le role avant d'attribuer un acces.
  • Un utilisateur inactif ne doit plus apparaitre dans les selecteurs operationnels.
  • L'admin mobile est online-only : il n'a pas besoin du mode offline terrain.

Si une action manque

  • Verifier que le compte connecte est bien ADMIN.
  • Retirer les filtres role ou statut dans la liste utilisateurs.
  • Rafraichir apres une creation ou une modification.
  • Si la galerie ne charge pas, verifier les variables R2 et les filtres chantier.
