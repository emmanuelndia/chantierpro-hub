Guide Direction

Role : DIRECTION

Version web + version mobile

Objectif du role

La direction suit l'activite globale : projets, chantiers, presences, rapports, photos, perimetres GS et logs. Elle consulte surtout, filtre et telecharge les informations utiles au pilotage.

Ecrans accessibles

Web : Tableau de bord global, Tous les projets, Presences / RH, Rapports terrain, Galerie photos, Perimetres GS, Logs de suppression et Profil.

Mobile : Accueil, Projets, Galerie, Perimetres GS et Profil.

Version webVersion mobileReglesProblemes frequents

Version web

Bureau

Consulter le tableau de bord global

Chemin : Menu lateral > Tableau de bord.

Ou appuyer : entree Tableau de bord.

Resultat attendu : les indicateurs globaux de l'activite s'affichent.

Consulter tous les projets

Chemin : Menu lateral > Tous les projets.

Ou appuyer : recherche, filtres ou carte projet.

Resultat attendu : la direction peut ouvrir les projets et verifier leurs chantiers.

Analyser les presences / RH

Chemin : Menu lateral > Presences / RH.

Ou appuyer : filtres periode, ressource, projet, chantier ou acces.

Resultat attendu : les presences correspondent aux pointages reels.

Consulter les rapports terrain

Chemin : Menu lateral > Rapports terrain.

Ou appuyer : filtres, ouvrir un rapport, telecharger si besoin.

Resultat attendu : les rapports terrain sont consultables sans informations parasites dans le fichier exporte.

Consulter la galerie photos

Chemin : Menu lateral > Galerie photos.

Ou appuyer : choisir un chantier, ouvrir une photo.

Resultat attendu : les photos se chargent depuis le stockage configure.

Suivre les perimetres GS

Chemin : Menu lateral > Perimetres GS.

Ou appuyer : filtres, ouvrir une ligne ou creer si le droit est disponible.

Resultat attendu : la direction voit quels sites sont confies aux superviseurs generaux.

Auditer les logs de suppression

Chemin : Menu lateral > Logs de suppression.

Ou appuyer : filtres date ou auteur.

Resultat attendu : les suppressions de photos sont tracables.

Version mobile

Telephone

Ouvrir l'accueil mobile direction

Chemin : Onglet Accueil.

Ou appuyer : cartes et raccourcis disponibles.

Resultat attendu : la direction consulte les informations essentielles sur telephone.

Consulter les projets mobile

Chemin : Onglet Projets.

Ou appuyer : ouvrir une carte projet ou chantier.

Resultat attendu : les projets et chantiers restent lisibles sur telephone.

Consulter la galerie mobile

Chemin : Onglet Galerie.

Ou appuyer : choisir un chantier puis ouvrir une photo.

Resultat attendu : les photos sont accessibles par chantier.

Consulter les perimetres GS mobile

Chemin : Onglet Perimetres.

Ou appuyer : ouvrir une carte de perimetre.

Resultat attendu : la direction suit les sites confies aux GS depuis mobile.

Ouvrir le profil

Chemin : Onglet Profil.

Ou appuyer : Profil, changer mot de passe si besoin, Deconnexion.

Resultat attendu : la session est consultee ou fermee proprement.

Regles importantes

  • La direction consulte surtout et pilote globalement.
  • Les presences doivent suivre les pointages reels.
  • Les photos supprimees doivent rester auditables dans les logs.
  • Certaines actions de gestion utilisateur restent reservees a ADMIN.

Si une action manque

  • Verifier que le role est bien DIRECTION.
  • Retirer les filtres trop restrictifs.
  • Verifier la periode selectionnee pour les rapports et presences.
  • Pour une action utilisateur, passer par un ADMIN si elle n'est pas proposee.
