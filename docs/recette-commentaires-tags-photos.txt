RECETTE - COMMENTAIRES ET TAGS RAPIDES SUR LES PHOTOS
=====================================================

Objectif
--------
Rendre les photos plus exploitables dans ChantierPro :
- ajouter un commentaire libre sur une photo ;
- ajouter des tags rapides ;
- garder le lien avec une tache planning ;
- conserver ces informations en mode offline ;
- les afficher dans la galerie et dans les rapports.

3. Action obligatoire avant test en production
----------------------------------------------

Avant de tester sur Vercel/Neon, appliquer la migration :

npx prisma migrate deploy

Sans cette migration, la base Neon ne connaitra pas :
- l'enum PhotoTag ;
- la colonne Photo.tags.


4. Comment tester sur mobile - photo avec tags
----------------------------------------------

Preconditions :
- Se connecter avec une ressource terrain autorisee a prendre des photos.
- Avoir au moins un chantier du jour.
- Idealement avoir une tache planning sur ce chantier.

Scenario :
1. Ouvrir la version mobile.
2. Aller dans Photo.
3. Selectionner le chantier.
4. Selectionner une tache si elle est proposee.
5. Saisir un commentaire, par exemple :
   "Debut des travaux sur la zone A".
6. Selectionner un ou plusieurs tags :
   - Debut tache
   - Preuve travaux
7. Prendre la photo.
8. Confirmer l'envoi.

Resultat attendu :
- La photo est envoyee.
- Le commentaire est conserve.
- Les tags sont conserves.
- La tache planning reste liee a la photo si elle a ete selectionnee.


5. Comment tester sur mobile - galerie
--------------------------------------

Scenario :
1. Ouvrir la galerie mobile.
2. Verifier que la photo envoyee apparait.
3. Ouvrir le detail/lightbox de la photo.
4. Verifier que les tags sont visibles.
5. Verifier que le commentaire est visible.
6. Utiliser le filtre par tag, par exemple "Preuve travaux".

Resultat attendu :
- La photo apparait avec ses badges.
- Le filtre par tag affiche uniquement les photos correspondantes.


6. Comment tester sur web - galerie
-----------------------------------

Scenario :
1. Ouvrir la galerie photos web.
2. Rechercher la photo prise depuis le mobile.
3. Ouvrir la lightbox.
4. Verifier les tags et le commentaire.
5. Utiliser le filtre par tag.

Resultat attendu :
- Les tags sont visibles sur les cartes et dans le detail.
- Le commentaire est visible.
- Le filtre par tag fonctionne.


7. Comment tester une photo liee a une tache dans un rapport
------------------------------------------------------------

Preconditions :
- Une ressource a une tache planning sur un chantier.
- Elle prend une photo en selectionnant cette tache.
- Elle soumet ensuite son rapport de session.

Scenario web :
1. Ouvrir le detail du rapport.
2. Descendre a la section Photos liees.
3. Verifier que les photos sont regroupees.

Resultat attendu :
- Les photos liees a une tache apparaissent sous un groupe "Tache - ...".
- Les photos sans tache apparaissent dans "Photos chantier".
- Les tags et commentaires sont visibles.

Scenario mobile :
1. Ouvrir le detail du rapport cote mobile, selon le role :
   - Coordinateur ;
   - GS ;
   - PM/Direction via rapports de gestion.
2. Verifier les photos associees.

Resultat attendu :
- L'action/tache apparait quand elle existe.
- Les tags sont visibles.
- Le commentaire photo est visible.


8. Comment tester le mode offline
---------------------------------

Preconditions :
- Le mode offline terrain est prepare.
- Le chantier et les taches du jour sont disponibles hors ligne.

Scenario :
1. Couper internet.
2. Aller dans Photo.
3. Selectionner le chantier.
4. Ajouter un commentaire.
5. Ajouter un ou plusieurs tags.
6. Prendre la photo.
7. Confirmer l'enregistrement offline.
8. Retablir internet.
9. Lancer la synchronisation.

Resultat attendu :
- La photo offline est synchronisee.
- Les tags sont conserves.
- Le commentaire est conserve.
- La tache liee est conservee si elle etait selectionnee.


9. Comment tester la validation API
-----------------------------------

Cas a verifier :
- Photo sans tag : acceptee, tags = [].
- Photo avec un tag valide : acceptee.
- Photo avec plusieurs tags valides : acceptee.
- Photo avec un tag invalide : refusee en 400.

Exemples de formats acceptes par l'API :
- tags en JSON :
  ["TASK_START","WORK_PROOF"]
- tags en CSV :
  TASK_START,WORK_PROOF


10. Points de non-regression
----------------------------

Verifier que :
- les anciennes photos sans tags s'affichent toujours ;
- la suppression de photo fonctionne toujours ;
- le telechargement de photo fonctionne toujours ;
- la galerie projet fonctionne toujours ;
- la galerie chantier fonctionne toujours ;
- les photos restent stockees dans R2 ;
- PhotoCategory continue d'exister et n'est pas remplace par les tags.


11. Limites de cette version
----------------------------

- Les tags sont une liste fermee en v1.
- Les tags ne remplacent pas les categories techniques de photo.
- Les rapports regroupent les photos par tache quand l'information existe.
- Les photos sans tache restent classees comme photos chantier.
